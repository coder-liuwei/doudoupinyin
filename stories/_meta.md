# 故事文件格式

`stories/*.txt` 是拼音王子的「内容源」。每个文件一篇故事。

## 文件结构

- 前若干行是**元信息**，以 `#` 开头；空一行后是正文
- 段间空一行（一个 `\n\n`）
- 段首不缩进（HTML 模板控制首行缩进 2em）
- 纯 UTF-8，不要带 BOM

## 支持的元信息字段

| 字段 | 说明 | 必填 | 示例 |
|------|------|------|------|
| `标题` | 显示在打印稿首行 | ✓ | `三打白骨精（节选）` |
| `作者` | 仅在 `.meta` 引用 | × | `吴承恩` |
| `出处` | 在打印稿副标题显示 | × | `西游记 第二十七回` |
| `拼音校对` | 校对日期（YYYY-MM-DD） | × | `2026-05-15` |
| `难度` | 学段提示（仅文档用） | × | `小学三年级` |

## 文件命名

- 文件名（不含 `.txt`）会作为故事 ID 用于：
  - 输出文件名（`<id>.html` / `<id>.pdf`）
  - 多音字词表的临时测试 fixture 名
- 以 `_` 开头的文件被视为**模板或元文档**，不会被 build 处理（如 `_template.txt`、`_meta.md`）

## 多音字覆盖

全局词表在 `data/polyphone.yaml`，对所有故事生效。逐故事的覆盖暂未支持（v0.1）。

## 校对工作流

1. 编辑 `stories/<id>.txt` 的正文
2. 跑 `python scripts/build_baigujing_html.py`（默认读第一个 story）
3. 跑 `python scripts/html_to_pdf.py`
4. 对照教材抽查**多音字**（行/还/长/佛/强/得/地/了/着/过/没/把/被）
5. 如有错误：编辑 `data/polyphone.yaml` 加 override → 重跑
6. 在 `# 拼音校对: YYYY-MM-DD` 更新日期

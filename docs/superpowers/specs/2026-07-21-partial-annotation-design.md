# 部分注音设计

## 目标

在不改变现有全文注音与校音能力的前提下，为当前稿件增加“注音范围”：全文注音、风险字注音、手动选择。默认继续使用全文注音。

## 已确认交互

- 全文注音：保持现有行为，所有有拼音的汉字显示拼音；候选读音和手动输入继续可用。
- 风险字注音：首次以现有读音风险算法判定的位置作为已选集合；风险只指读音不确定，不扩展到年级生字。
- 三种范围模式只负责过滤哪些拼音可见，不改变点击文字的校音交互；点击任何可校音汉字都打开同一候选卡，并继续支持候选读音和手动输入。
- 手动选择：首次进入时已选集合为空，因此隐藏全部拼音。
- 风险字和手动选择共用相同的候选按钮规则：已注音时当前读音候选为选中态，未注音时所有候选均不选中。
- 点击未选候选会设置该读音并添加当前位置的注音；点击其他候选会切换读音并保持注音；再次点击当前已选候选会取消当前位置的注音。
- 点击文字本身只打开候选卡，不立即改变注音；完成手动输入会更新读音并添加当前位置的注音。
- 全文注音仍保持原行为：当前读音始终选中，点击当前候选不取消注音。

## 数据与边界

- 保留完整 `Paragraph` / `Pair` 数据，部分注音只控制预览和打印层的显示，不删除拼音，也不修改共享 `Pair` 契约。
- `AnnotationSettings` 使用 `mode` 保存当前范围模式，`manualKeys` 与 `riskKeys` 分别保存两种过滤模式已选中的 `段索引:字索引`；不修改共享 `Pair` 契约。
- 生成新稿时 `manualKeys` 初始化为空，`riskKeys` 按当前风险结果初始化；清空编辑器时恢复默认全文注音并清空两套位置。
- 风险字与手动选择分别保留自己的集合，模式切换不会相互覆盖；重新进入时恢复该模式上次的选择。
- 保存历史与临时打印载荷时附带可选 `annotationSettings`；旧历史缺少该字段时按全文注音读取。
- 旧数据只有 `manualKeys` 或缺少 `riskKeys` 时，从保存的段落风险结果初始化 `riskKeys`；显式保存的空数组必须视为用户已清空，不能重新推导。
- 风险集合首次初始化复用 `analyzeReviewRisks`，不复制另一套判定逻辑；初始化后由用户选择结果驱动，不因校音自动删除已选位置。

## 渲染

- 隐藏拼音时保留 ruby 的占位高度与字宽，只将 `rt` 设为不可见，避免正文跳动。
- 屏幕预览和独立打印路由使用同一套注音可见性计算。
- 风险字和手动模式为已选字增加轻量高亮，并显示当前模式的已选数量和“清空注音”；清空只影响当前模式的集合。
- 候选卡需要把“当前读音”和“是否注音”分开：顶部仍展示当前读音，候选按钮仅在当前位置已注音且读音匹配时显示选中态。
- 标点、英文和数字不参与选择，也不改变现有合并与排版行为。

## 验证标准

- 旧稿和新稿默认仍为全文注音。
- 三种模式的屏幕预览与打印结果一致。
- 三种范围模式点击文字都打开相同的候选读音和手动输入弹窗。
- 风险字和手动模式下，未注音位置打开弹窗时没有候选选中；点击候选后才添加并显示注音。
- 风险字和手动模式下，点击当前已选候选会取消注音，点击其他候选会切换读音且保持注音。
- 手动输入保存后会添加注音；取消注音与清空注音都只改变可见集合，不删除完整拼音数据。
- 风险字和手动选择分别保留，模式切换、保存历史、重新打开和打印后均保持一致。
- 全文注音的候选选择和手动输入行为不回归，也不允许取消单字注音。
- 现有测试、构建通过，且不修改 `src/lib/types.ts`。

## 对抗性审查

- 验证同一个汉字的不同出现位置互不影响，不能按字面值批量改动。
- 验证未注音但已有当前读音时没有候选误选中，点击当前读音可以正常添加注音。
- 验证已注音时点击当前候选会取消，点击其他候选只切换读音，不会先取消再丢失状态。
- 验证风险字和手动两套集合在反复切换、分别清空后互不污染。
- 验证显式空 `riskKeys` 保存并重新打开后仍为空，不会被旧数据兼容逻辑重新填充。
- 验证候选选择、手动输入、关闭弹窗、按 Escape、点击弹窗外部的状态变化没有竞态或误提交。
- 验证打印临时载荷、历史保存、旧记录读取、重新生成正文和清空稿件的边界行为。
- 验证全文注音、标点、英文、数字、键盘 Enter/Space 操作与无障碍选中态没有回归。

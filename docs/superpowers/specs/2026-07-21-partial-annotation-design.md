# 部分注音设计

## 目标

在不改变现有全文注音与校音能力的前提下，为当前稿件增加“注音范围”：全文注音、风险字注音、手动选择。默认继续使用全文注音。

## 已确认交互

- 全文注音：保持现有行为，所有有拼音的汉字显示拼音；候选读音和手动输入继续可用。
- 风险字注音：只显示现有读音风险算法判定的字；风险只指读音不确定，不扩展到年级生字。
- 手动选择：首次进入时隐藏全部拼音，点击某个字只切换当前出现位置；再次点击取消该位置的注音。
- 手动模式始终只负责决定哪些拼音显示，不打开候选卡，也不设置“完成选择”或“调整选择”状态。
- 全文注音和风险字模式保持现有校音行为，点击文字仍可打开候选读音与手动输入。
- 修改候选读音或手动输入后，正文拼音立即更新，当前字的显示选择不变。

## 数据与边界

- 保留完整 `Paragraph` / `Pair` 数据，部分注音只控制预览和打印层的显示，不删除拼音，也不修改共享 `Pair` 契约。
- 新建独立 `AnnotationSettings`：`mode` 保存范围模式，`manualKeys` 保存手动选中的 `段索引:字索引`。
- 生成新稿和清空编辑器时恢复默认全文注音并清空旧位置；普通模式切换保留当前稿的手动选择，方便往返比较且避免误删。
- 保存历史与临时打印载荷时附带可选 `annotationSettings`；旧历史缺少该字段时按全文注音读取。
- 风险模式复用 `analyzeReviewRisks`，不复制另一套判定逻辑。人工校正后该字不再属于当前风险结果。

## 渲染

- 隐藏拼音时保留 ruby 的占位高度与字宽，只将 `rt` 设为不可见，避免正文跳动。
- 屏幕预览和独立打印路由使用同一套注音可见性计算。
- 手动模式为已选字增加轻量高亮，工具条只提供已选数量和“清空注音”；清空必须由用户主动触发。
- 标点、英文和数字不参与选择，也不改变现有合并与排版行为。

## 验证标准

- 旧稿和新稿默认仍为全文注音。
- 三种模式的屏幕预览与打印结果一致。
- 手动模式点击当前字只添加或取消该位置的注音，绝不打开校音弹窗。
- 从手动模式切换到全文或风险字后，既有手动位置仍被保留；再次切回时恢复原选择。
- “清空注音”会清除全部手动位置，但不删除正文中保存的完整拼音数据。
- 全文和风险字模式下，候选读音及手动输入仍能回写完整拼音。
- 保存、重新打开和打印后，模式与手动选择保持一致。
- 现有测试、构建通过，且不修改 `src/lib/types.ts`。

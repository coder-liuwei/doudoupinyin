# 兜兜拼音交互式架构图设计

## 目标

新增一个可独立打开的单文件 HTML 架构图，帮助参赛材料撰写、技术讲解和后续追问。图中内容必须对应当前代码实现，重点解释内容解析如何连接输入、注音校正、人工校对、历史存储和打印输出。

## 交付范围

- 新增 `docs/architecture.html`，CSS、JavaScript 和 SVG 图标全部内嵌。
- 不修改 React 应用、路由、依赖、构建配置或公共组件行为。
- 不引入 CDN、字体或图片等外部资源，离线打开仍可完整使用。
- 不修改现有 `AGENTS.md` 和 `.codegraph/daemon.pid`。

## 信息架构

页面采用“分层系统地图 + 中央数据流”，分为五层：

1. 输入层：文本粘贴、PDF 导入、单行/双行模式。
2. 内容解析层：PDF 逐页抽取、坐标排序、文本清洗、NFKC 规范化、单行分段、双行配对校验。
3. 语言处理层：逐字 Pair 建模、`pinyin-pro` 基础注音、YAML 多音字覆盖、结构助词校正、冲突降级。
4. 状态与校对层：Zustand 编辑状态、风险高亮、单字/词组人工修订、本地历史记录。
5. 展示输出层：Ruby 预览、学段字号与版式设置、独立打印路由、A4/PDF 输出。

主链路展示正常数据流；橙色虚线表示校验失败、词表冲突和人工兜底路径。每个节点标注真实模块或函数名称。

## 交互设计

- 默认展示完整架构，点击节点打开右侧详情面板。
- 详情包含：职责、输入、输出、关键规则、异常处理和对应代码路径。
- 提供“产品视角”“技术视角”“聚焦内容解析”三种视图。
- 选中节点时突出上游和下游，弱化无关节点。
- 支持键盘聚焦与 Enter/Space 激活；Esc 关闭详情。
- 窄屏下层级纵向排列，详情面板转为页面内卡片。
- 尊重 `prefers-reduced-motion`，关闭非必要动画。

## 视觉设计

采用“儿童学习产品 × 技术蓝图”的编辑式视觉：米白纸张背景、靛蓝主色、绿色正常链路、橙色风险链路。卡片保留适度圆角和柔和双层阴影，但避免过度卡通化。标题使用具有中文书刊感的本地字体栈，正文强调长文本可读性。图标使用内嵌 SVG，颜色不作为唯一状态表达。

## 真实数据流

### PDF 输入

`PdfImport.onFile` → `extractPdfText` → `pdfjs.getDocument` → 按页读取 `getTextContent` → 按 Y/X 坐标排序 → 合并换行并清洗 → 写入编辑器输入并切换为单行模式。

### 生成注音

`ActionPanel.handleGenerate` → `normalizeInput` → `splitPlainBlocks` 或 `buildDualParagraphs` → 生成 `Paragraph[] / Pair[]` → `loadTable` → `applyTable` → `fixParticles` → 写入 Zustand。

### 校对与输出

Zustand 中的 `updatePairPinyin` / `updatePairPinyinRange` 标记人工修订；预览与打印复用 Ruby 渲染核心。保存时将原文、段落和打印设置写入本地历史；打印通过 `/print?id=...` 独立路由隔离 Tailwind preflight。

## 错误与边界

- 空输入或无法分段：停止生成并显示错误。
- 双行格数不一致、顺序错误或汉字格非单字：抛出明确中文错误。
- 多音字 override 区间冲突：保留基础注音，提示已降级。
- PDF 解析失败：保留当前编辑内容并显示失败原因。
- 架构图本身不读取项目数据、不发起网络请求、不修改本地存储。

## 验证标准

- 直接双击 `docs/architecture.html` 可打开，控制台无错误。
- 桌面宽屏下主图和详情面板均完整可见。
- 375px、768px、1440px 宽度下无横向内容遮挡。
- 三种视图切换正确，所有节点可点击和键盘访问。
- “内容解析”聚焦视图覆盖文本与 PDF 两条输入路径及单行/双行两个分支。
- 页面不依赖网络资源，关闭网络后功能不受影响。
